# 从 Skill 流程到题序功能

更新：2026-10-13。以下提取的是教学工作流的职责与验收标准，不复制某个 AI 的执行环境。用户用网站选择材料、设定任务、接收提案；AI 提供判断和建议；编辑器保存可编辑副本。所有任务默认在本机组装，用户自行选择 AI；网站不自动上传资料。

## 本轮提供的任务模板

| 网站流程 | 参考 Skill | 输入 → AI 工作 → 交付 | 当前实现与人工验收 |
| --- | --- | --- | --- |
| 按方法分类汇编 | `math-exam-insight-compilation` | 完整候选题、来源与教学目标 → 比较任务、关键动作及边界 → 题包、建议题序、分类角色与依据 | 可导出任务与候选题、回导预览并追加。分类名作为教师角色备注；尚无独立章节块与统计洞见页。教师核对分组机制、来源和独立证据，不能以题目形式代替方法分类。 |
| 方法递进讲义 | `math-method-ladder-handout` | 核心方法、目标能力、学生基础 → 从终点反向设计台阶 → 基元、梯度、桥接、迁移题序及通过标准 | 可通过同一题包回导。首版只重组已有题，暂不允许模板要求 AI 自编新题。教师核对新增障碍、承接和终点可达性。 |
| 答案审校任务 | `audit-shanghai-math-markdown` | 完整题面、原答案解析与配图 → 独立求关键结论再对照原解 → 教学备注中的原文、疑点、推导证据、建议及未解决项 | 提供审校任务模板和结果回导。保持原解，建议进入备注；尚无逐条补丁接受/拒绝界面，也不宣称执行了独立数学双审。 |

本轮状态为「可导出任务、外部 AI 执行、结构校验、教师预览应用」，不是网站内置模型或 Skill 运行器。AI 的 role/reason 写入讲义副本教学备注，学生版排除这些字段。格式正确不等于数学正确。

## 值得继续做的网站流程

| 流程与参考 Skill | 可做的网页 | 前置条件与验收 |
| --- | --- | --- |
| 卡点备课与复测：`coordinate-learning-diagnosis` | 题目 → 备课预判 → 探查问句 → 练习及通过标准 → 真实复测记录 | 无学生证据只做预判。有原话、草稿和作答条件才做个人诊断；需要独立私有存储，不能把个人记录混入公共题库。 |
| 母题与变式：`math-question-adaptation-goon` | 母题关系图、变化维度、分层练习草案、对照解答 | 必须完整求解并复核条件相容性、边界与唯一性，记录 derivedFrom，不把变式覆盖成原题。 |
| 来源与题目归档：`ingest-math-exam-questions` | 批次 → 来源 → 单题 → 待核清单 → 归档 | 本轮只保存题包身份/版本与工作区，尚不是文件题库归档；需先实现版本事实源、持久化及可恢复迁移。 |
| 讲义质量检查：`high-school-math-handout-pipeline`、`lecture-pdf-layout` | 同源双版 → 题序/答案隔离检查 → 图片/公式/分页检查 → 输出回执 | 复用现有打印，补充实际 PDF 检查；不能用“渲染成功”代替数学审校或逐页视觉验收。 |

## 通用产品结构

1. **任务模板**：目标、材料范围、允许修改范围、AI 交付规范与人工通过标准。
2. **标准题包**：每题显式 Markdown 字段、稳定身份与版本、配图、建议题序；网页与 CLI 使用同一校验器。
3. **预览与应用**：完整展示材料，校验冲突，不覆盖旧题；选题依据进入教师字段，操作可撤销。
4. **后续提案层**：扩展章节、审校 findings、证据引用、逐条补丁和基础版本冲突检查；新增协议字段需版本化，不在本轮已发布 v0.1 中私自加字段。

先复用一个可靠操作层，再接不同模型的 API、CLI 或 MCP。题目数据与协议属于项目，不应锁在某个对话、提示词或 AI 服务中。
